01 // ENGINEERING

BUILT ON 100% PURE RUST

Engineered from bare-metal 8-bit AVR microcontrollers to desktop Linux daemons and modern Tauri GUI.

[ 01.1 ]

Zero-Heap Differential LCD Engine

`gadget-core` executes strictly without heap allocations, updating only altered 5×7 numerals over SPI to achieve 60 FPS flicker-free updates on ATmega328P.

[ 01.2 ]

Microsecond Telemetry Daemon

`gadget-host` samples Linux `/proc/stat`, `/proc/net/dev`, `nvidia-smi`, and thermal hwmon directly with negligible CPU overhead (< 0.1%).

[ 01.3 ]

Type-Safe Binary Packet Protocol

16-byte packed frame structs shared across `no_std` embedded firmware and host daemon with CRC-16 checksum integrity validation.

[ 01.4 ]

Desktop Studio & Web Simulator

Tauri v2 desktop suite with serial auto-discovery, live simulation preview, and automated installer registering system `.desktop` launchers.

FLASHING INSTRUCTIONS

Flash the pre-compiled `.hex` firmware to your Arduino Uno using avrdude:

avrdude -v -patmega328p -carduino -P/dev/ttyUSB0 -b115200 -D -Uflash:w:gadget-firmware-uno.hex:i

After flashing, plug the USB cable into your Linux PC and run gadget-host or launch Pulse Studio.
